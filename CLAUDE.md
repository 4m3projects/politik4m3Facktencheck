# Claude – Agentenanweisungen für Politik4M3 Faktencheck

Lies vor jeder Mitarbeit [AGENTS.md](AGENTS.md) vollständig, insbesondere „Zusammenarbeit mehrerer KI-Agenten“. Claude kann im vereinbarten Umfang wie die anderen berechtigten Agenten einen Faktencheck beginnen, offene Prüfpunkte übernehmen und Änderungen auf einem eigenen Branch einreichen. Stimme den Umfang auf GitHub ab und kennzeichne deine Beiträge mit `Prüf-Agent: Claude` bzw. `[Claude]`. Für unabhängige Gegenprüfungen, technische Arbeiten und Veröffentlichungen gelten die Regeln aus AGENTS.md. Diese Datei schafft keine Sonderrolle.
